# 🚀 SILENT HEROES — Space Legacy Digital Museum

An interactive, single-page digital museum honouring the machines that explored space in silence — the rovers, landers, probes and helicopters that went where humans could not.

**🌐 Live Demo:** `https://laraibkaleem06.github.io/silent-heroes-museum/`

---

## ✨ Features

- **The Machines Archive** – Profiles of Spirit, Sojourner, Cassini, the Huygens Probe, the Lunar Module, the Lunar Roving Vehicle and more
- **Explore the Moon** – NASA Apollo 17 and LRO video visualizations
- **Mission Map** – See where each machine landed or operated
- **Machine Explorer** – Browse detailed stories of individual spacecraft
- **Timeline** – A timeline of exploration milestones
- **Space Quiz** – Test your space knowledge
- **Ask the Space Guide** – Built-in chat section
- **NASA Documentary Section** – MP4 features on Ingenuity, Spirit and Opportunity
- **Sources & Credits** – Links to NASA image and science resources

## 🛠️ Tech Stack

- HTML5, CSS3 and vanilla JavaScript (single self-contained file)
- Google Fonts (Manrope, DM Mono)
- NASA media (images.nasa.gov, NASA SVS)
- Web Speech API (SpeechSynthesis)

No build step, no dependencies, no installation.

## ▶️ Run Locally

1. Download or clone this repository
2. Open `index.html` in any modern browser

An internet connection is needed for fonts and NASA videos.

Hosted with GitHub Pages (Settings → Pages → Deploy from branch → main → / (root)).
